# MemoApp
1. 로그인
    - 앱 실행 시
        - 로그인 되어 있을 경우 → HomeView
        - 안 되어 있을 경우 로그인 시도
            - 가입되어 있을 경우 로그인 후 → HomeView
            - 가입되어 있지 않을 경우 → RegisterView로 이동하여 회원가입 진행
                - 회원가입 후 → LoginView로 이동하여 로그인 → HomeView
    - 앱 삭제 시 모든 로그인 데이터는 삭제됨
    
2. 회원가입
    - 이메일과 비밀번호로 가입
        - 정규표현식을 사용하여 @.com 등의 형식으로만 이메일 가입 가능
        - 비밀번호는 자유롭게 설정 가능
        
3. 메모 홈 뷰
    - CoreDate에서 id 별로 저장되어 있는 Memo를 불러옴
    - LazyVGrid로 리스트 형식으로 메모를 보여줌
        - 메모 작성 시 올린 이미지 → 썸네일
        - 메모 내용 → 요약되어 썸네일 하단에 표시
    - 작성된 메모
        - 메모 탭 → MemoDetailView로 이동하여 메모 확인 가능
        - 메모를 꾹 눌렀을 때 → 삭제 Alert를 띄운 후 → 삭제 가능
    - 메모 작성
        - 메모 홈 뷰 오른쪽 하단 연필 표시 클릭 시 → 연필 표시가 일시적으로 커짐 → MemoWriteView 이동
        
4. 메모 작성 뷰
    - 이미지와 메모 내용을 작성하여 저장할 수 있음
        - 이미지 → PhotosPicker
            - ViewModel에서 이미지 데이터 관리
        - 내용 입력 후 저장 시 → ViewModel에서 Memo CoreData에 저장
            - 저장 후 → HomeView 로 이동
5. 메모 삭제
    - 사용자가 선택한 메모의 이미지와 본문 내용을 볼 수 있음
